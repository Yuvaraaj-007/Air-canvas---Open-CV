### Air Canvas using OpenCV

Draw in the air using your hand with real-time gesture tracking. This project uses **OpenCV** and **MediaPipe** to create a virtual drawing canvas without touching the screen.

## Features

- 🖐️ Real-time hand tracking
- 🎨 Multiple color selection
- ✍️ Air drawing using index finger
- 🧹 Eraser tool
- ♻️ Clear canvas option
- 📷 Live webcam interface

## 🛠️ Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy
